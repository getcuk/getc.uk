Well; you might think this question is redundant. To become a programmer or coder; of course you start with basics and work your way up. But in reality; it’s not always the case.

The programming world has a structure :

- There are people who mastered the basics of programming that takes quite bit of time / effort and then became application / software developers and let’s call them **‘real’** programmers or coders.
- Then there are people who learned few languages by tinkering with them and now can write code that will just do the job. It will not be the best code written. It might fail few tests here and there but by the magic of **'copying & pasting'** from other applications or from question forums; these guys can patch-up the software and make it work **'fingers crossed'**. These guys won’t necessarily know how the application that they are patching up works under the bonnet or whether the endless list of libraries it calls makes it bloated or slow or error-prone. But they want to get job done and that’s the only way they have learned so far.  
- Lastly there are people; they do not know how to code at all but they still work with software. They implement the software, install it by following documentation and get the end result. These guys can also go into the habit of **'copying & pasting'** and then they will come under second category explained above.

Let’s merge the last two groups of people and call them **'implementers'**. Being an implementer is not a bad thing. Sometimes; that’s the only way to start into the programming and put food on the table if you start working on the projects. But remaining a life-long implementer even when you know you can improve is a terrible thing.    

Now; it begs the question from implementers like myself:  Why learn the basics of coding ?  

Learning the basics of coding gives us ability to solve problems using computers as long as we have the recipe or the algorithm. It could be writing a program that analyses the data from weather sensors, a website that saves entries in the database for later search retrieval for end users or any other application that can be invented to solve a practical problem. If the basics of programming are not clear; the first thing one does is to look for already made solutions and if he/she finds one; it’s almost always not quite the solution he/she is looking for. It might not allow changes. It could be poorly written or the code you would write to customise it; might not work or worse interfere with something else on the program. Not mastering the coding fundamentals forces the so-called coder down the rabbit hole.  

Hence; I created this website where I am writing articles about my journey through learning programming thoroughly but incrementally starting with C.

#### Now Why C ?

C is one of the oldest languages that gives access to the concepts that do not exist any more in modern high level languages and provides control of the computer that is otherwise not possible. Therefore; it helps to learn to create lean software.
